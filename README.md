# AI Assistant

A Python AI assistant built from scratch.

## Features

- Conversational chatbot
- JSON knowledge base
- Modular architecture
- Easy to expand
- OpenAI API ready

## Project Structure

```
AI/
├── app.py
├── chatbot.py
├── utils.py
├── data/
├── models/
└── README.md
```

## Run

```bash
pip install -r requirements.txt

python app.py
```
